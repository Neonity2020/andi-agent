andi-agent

一个使用 Bun + TypeScript 构建的最小 coding agent，默认调用 Agnes 2.5 Flash。

概述

andi-agent 是一个可在本地工作区内安全执行编程任务的 AI 代理。它通过 OpenAI 兼容的流式 API 与模型交互，支持多轮工具调用、会话持久化与命令审批，专注于最小化依赖与最大安全性。

快速开始

bun install
cp .env.example .env
# 编辑 .env，填写 AGNES_API_KEY
bun run start -- --cwd . "阅读 README，创建项目摘要"

核心能力

📁 文件操作

read_file、write_file、edit_file，路径穿越防护，拒绝符号链接写入，.andi-agent 目录受保护。

🔍 代码搜索

search_code 基于 ripgrep，按固定字符串匹配，自动跳过 .git、node_modules。

⚡ 命令执行

run_command 无 shell 执行白名单命令（bun/npm 验证脚本、tsc），其余命令需终端逐条审批。

🔧 Git 集成

git_status、git_diff 只读查看，git_stage 与 git_commit 要求审批，不自动 push。

💬 会话持久化

使用 --session ID 保存和恢复多轮上下文，存储于本地 .andi-agent/sessions/，不会提交到 Git。

🔄 交互式 REPL

启动 --repl 进入持续进程，内置 /help、/status、/clear、/exit 命令。

安全设计

  • 所有文件操作限定在工作区边界内，拒绝路径穿越与符号链接写入。
  • 命令执行仅白名单内脚本自动通过，其余等待终端审批或默认拒绝。
  • 环境变量脱敏：仅透传 PATH、LANG、TERM 等安全变量。
  • Git 操作统一通过专用工具，禁用 external diff、textconv 等仓库扩展。
  • 上下文超限时按完整用户轮次裁剪，保留最近交互以保证连贯性。

命令参考

# 单次任务
bun run start -- --session feature-auth "分析认证模块"

# 持久 REPL
bun run start -- --repl --session real-dev --approval ask

# 帮助
bun run start -- --help

# 类型检查 & 测试
bun run typecheck
bun test
